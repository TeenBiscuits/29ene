# Criterios editoriales y actualización

## Independencia y claridad

La guía informará sin recomendar un voto. Los criterios para seleccionar y ordenar la información serán públicos. Se distinguirán los hechos comprobados, las propuestas de los partidos y cualquier análisis.

El lenguaje será sencillo. Las visualizaciones deberán permitir comprender qué información muestran y de dónde procede. Cada contenido informativo tendrá fuentes enlazadas y fecha de última revisión.

## Publicación

El responsable del proyecto aprobará las publicaciones. Las aportaciones de otras personas se realizarán mediante pull requests. Cada cambio de contenido se publicará simultáneamente en español, galego, català y euskara.

Antes de publicar un cambio se comprobarán las fuentes, la fecha de revisión y la correspondencia del contenido en los cuatro idiomas. El método concreto de revisión lingüística está pendiente de definición.

Las fechas electorales y los trámites se contrastarán con las fuentes oficiales pertinentes. Se distinguirá un anuncio de una convocatoria formal publicada y se indicará el estado de confirmación cuando corresponda. El contenido de `calendar.html` se incorporará en una fase posterior.

## Correcciones y problemas

Se crearán dos plantillas de GitHub Issues:

| Plantilla | Información solicitada |
| --- | --- |
| Corregir información | Contenido afectado, corrección propuesta y fuente que la respalda. |
| Problema de la web | Idioma, dispositivo y pasos para reproducir el problema. |

La web enlazará directamente a cada plantilla. Junto a los enlaces se explicará que GitHub requiere una cuenta y que los informes son públicos. Las plantillas y los enlaces están pendientes de implementación.

El repositorio indicado en la documentación existente es `TeenBiscuits/29ene`. Antes de incorporar enlaces públicos se comprobará que ese sea el destino definitivo.
